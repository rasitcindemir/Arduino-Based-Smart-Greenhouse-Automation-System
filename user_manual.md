# User Manual & Operating Guide

## Bluetooth Pairing & Setup
1. Power on the greenhouse system.
2. Open your smartphone's Bluetooth settings and search for devices.
3. Pair with the **HC-05** module (Default pairing PIN: `1234` or `0000`).
4. Open any standard Bluetooth terminal application on your phone (e.g., *Bluetooth Serial Controller*).

## Control Command Reference
You can override automated routines by sending single-character commands via the Bluetooth terminal:

| Command | Action | Description |
| :---: | :--- | :--- |
| **`P`** | Pump ON | Manually forces the water pump relay to engage. |
| **`p`** | Pump OFF | Manually turns off the water pump relay. |
| **`F`** | Fan ON | Manually forces the cooling fan relay to engage. |
| **`f`** | Fan OFF | Manually turns off the cooling fan relay. |
